# Quality 0.1.0

This minor release adopts the Methods 1.5 series, Core 0.6 and DAG-ML 0.5.
The owner cohort includes numerical corrections since the previously staged
Methods 1.3.15 release, including near-zero autoscaling and wide preflight PCA
scores. Existing numerical results can change; calibration, diagnostics and
replay must be qualified against the actual delivered artifacts.

The app's optional Methods peer and its measured runtime admission now accept
the selected 1.5 series (`>=1.5.0 <1.6`) with ABI `>=2.24 <3`. An old binary cannot
be admitted by changing its package label. A future minor series requires an
explicit consumer decision and qualification.

The guided lab workflow, identity and evaluation provenance, manual profile
activation, training-only fitting and explicit unavailable/refused results retain
their existing contracts. Selection-validation scores do not become independent
evaluation, and heuristic uncertainty bands do not become calibrated intervals.

The exact public projections are Core 0.6.0, DAG-ML 0.5.0 and Methods 1.5.1.
Their registry/source identities and file hashes are recorded in
`app/vendor/owners-current/DELIVERY.json`. Methods 1.5.1 fixes Python concurrent
initial imports without changing the 1.5.0 numerical code or ABI 2.24. The IO and
Formats browser artifacts retain their own provenance and admission checks;
new Methods/Core/DAG versions do not certify those independent profiles.

This final public cohort passes typecheck, Methods admission (4), Assessment (33),
real-WASM science (19) and calibration (17), unchanged PLS (11) and Ridge (4)
production parity, model import (47 cases), and workspace storage with an included
model. All three actual Chromium journeys and both served/single-file builds
pass. The original historical Core and Methods reference bytes, numerical values
and tolerances are unchanged. These results qualify the named Quali profile,
not generic cross-host execution or an independent outer evaluation.

All 16 upstream Methods notices accompany served and offline outputs with exact
source/archive/hash provenance. Distribute the companion notices with offline
HTML. No candidate binary has been relabelled or substituted for a published
package. Local qualification and independent Opus review pass. Release tagging and
deployment remain separate delivery steps.
